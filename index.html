Problem Statement

Construct an optimally diversified equity portfolio that maximizes risk-adjusted returns while explaining systematic factor exposures via the Fama-French 5-Factor model.

Methodology

  • Historical return data for 10 US large-cap stocks scraped via yfinance
  • Efficient frontier computed using CVXPY quadratic programming
  • OLS regression against SMB, HML, RMW, CMA, and market beta
  • 5,000 Monte Carlo portfolio simulations for distribution analysis
  • Out-of-sample walk-forward backtest over 12-month window

Key Results

  • Maximum Sharpe Ratio portfolio: Sharpe ~1.4 (annualized)
  • Minimum Variance portfolio: Volatility ~11% annualized
  • Factor model R² ~0.78 — strong systematic factor coverage

Tools

Python · NumPy · pandas · scipy · cvxpy · statsmodels · matplotlib · yfinance

GitHub

Problem Statement

Compare three leading portfolio construction approaches to understand trade-offs between pure optimization, Bayesian updating, and growth-optimal allocation.

Methodology

  • Black-Litterman: combined CAPM equilibrium returns with 3 investor views using tau = 0.05
  • Kelly Criterion: full Kelly and fractional Kelly (0.5x) for long-term growth optimization
  • MVO benchmark using equal prior returns
  • Monte Carlo performance distribution for all three strategies

Key Findings

  • Black-Litterman produced more stable allocations than pure MVO under view uncertainty
  • Full Kelly showed higher expected growth but significantly higher drawdown risk
  • Half-Kelly balanced growth and drawdown most effectively in backtests

Tools

Python · NumPy · pandas · scipy · matplotlib · cvxpy

Applied Ledoit-Wolf shrinkage to denoise the covariance matrix of a 12-asset portfolio. Comprehensive risk-adjusted performance evaluation via Sharpe, Sortino, CVaR, Calmar, and Max Drawdown.

LW Shrinkage
GitHub

Problem Statement

Improve portfolio optimization reliability by addressing estimation error in sample covariance matrices using statistical shrinkage techniques, then evaluate true risk-adjusted performance comprehensively.

Methodology

  • Ledoit-Wolf analytical shrinkage applied to 12-asset covariance estimation
  • Comparison of sample covariance vs. shrunk covariance portfolios
  • CVaR at 95% confidence computed via historical simulation
  • Calmar ratio and Maximum Drawdown via rolling window analysis
  • Sortino ratio computed using downside deviation

Key Results

  • Shrinkage reduced portfolio volatility by ~18% vs. sample covariance baseline
  • CVaR improved (reduced) from -2.3% to -1.9% daily at 95% confidence
  • Sharpe Ratio improved from 0.92 to 1.21 with denoised covariance

Tools

Python · scikit-learn (LedoitWolf) · NumPy · pandas · scipy · cvxpy · matplotlib
